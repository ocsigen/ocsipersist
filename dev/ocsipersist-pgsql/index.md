
# ocsipersist-pgsql

PostgreSQL backend for Ocsipersist. For the API documentation see OPAM package [ocsipersist](../ocsipersist/Ocsipersist/index.html). This page describes how to configure the PostgreSQL backend.


## Using as a library

If you are not using Ocsigen Server's configuration file, add library `ocsipersist-pgsql.settings` in your Dune file, and use module [`Ocsipersist_settings`](./Ocsipersist_settings.md) to configure the storage file.


## Using with Ocsigen Server: ocsipersist-pgsql-config

If you want to configure Ocsipersist-pgsql from Ocsigen Server's configuration file, use package [ocsipersist-pgsql-config](../ocsipersist-pgsql-config/Ocsipersist_config/index.html).
